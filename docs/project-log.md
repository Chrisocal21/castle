# Castle Builder: Project Log

## 2026-11-18: Concept session

Chris wants a new voxel game in the style of Miniopolis with a castle theme.

Research findings (Miniopolis, by Radiangames, Steam release listed as Q1 2027):
- Building is drag a selection box, then extrude or subtract blocks.
- Six main building blocks plus utility blocks (lights, trees, parking).
- Resource-free sandbox. No zoning, utilities or unhappy citizens.
- Developer says there will be a little progression to unlock features.
- Weather, time of day and depth of field are player controlled.
- Whole city mesh regenerates on every edit (developer's own note).
- Not published: world size, bounded or endless, save and share features.

Decisions made, in order:
1. Strictly a builder, same as Miniopolis.
2. Browser first, Three.js.
3. Building is drag-extrude, not premade pieces. Chris wants half and quarter steps on top, and auto-shaping.
4. Six materials: light stone, dark stone, brick, timber, plaster, roof tile.
5. Miniature diorama look (Forge recommendation accepted).
6. Bounded plot (Chris: same or similar to Miniopolis; size left to tune).
7. Everything unlocked from the start (Forge recommendation accepted).
8. Free orbit camera with photo mode (Forge recommendation accepted).
9. Autosave, export and import, screenshot for version 1.
